# ADR 010: ガウス場を点ごとに変換して、ζ の符号を選べる密度場の模型を作る

## Context

`manager::three_point::field_mocks` の密度場の模型（G）は、点の池から選んだ中心に正負半々の符号をつけた幅 σ のガウス関数を足し、各点で √ΣK² で割った単位分散の場 g を作り、店の密度を「基準 × max(0, 1 + A g)」とする（2026-11-16 確認）。
符号が対称なので、切る前の δ = A g の三次のモーメントは 0 で、G は ζ ≈ 0 の模型である。

ノート `notes/retail-cosmology-beyond.tex` の選択関数の幅 R を変えた節では、ζ̂_S を ξ̂_S の二乗で割った Q̄_S を比べた（2026-11-16 確認）。
コスモスは R = 50〜150 km で Q̄_S ≈ −0.9〜−0.67 だった。
NS（ζ > 0）と、W の幅・振幅・場の幅を変えた G の八つの模型（各 20 個）は −0.3 より負にならず、R ≥ 70 km でコスモス以下になったのは 160 個のうち各 R で 1 個だった。
ζ ≈ 0 と ζ > 0 の模型しかないので、「ζ < 0 の場なら S を通した後に Q̄_S ≈ −0.7 になるか」をまだ確かめられない。

コスモスの ξ̂_S は 3〜24 km で正（R = 150 km で 0.33〜0.22）なので、比べる模型は ξ > 0 のまま ζ < 0 を持つ必要がある。

## Decision

1. G の単位分散の場 g に、点ごとの変換 T をかけてから振幅を掛ける。δ = A T(g)。変換は次の三つで、既定は恒等変換とする。
   - 恒等：T(g) = g（今の G）。
   - 正の歪み：T(g) = (g² − 1)/√2。
   - 負の歪み：T(g) = (1 − g²)/√2。
   二つ目の成分（幅の違う独立な場）がある場合は、成分ごとに同じ T をかけて足す。
2. 正と負の歪みの変換は、g が相関係数 ρ のガウス場なら、平均 0・分散 1 で、
   ξ = A² ρ²、ζ = ±2√2 A³ ρ₁₂ρ₂₃ρ₃₁ になる（Wick の定理、切る前）。
   二つの変換は ξ が同じで ζ の符号だけが逆になるので、S を通した Q̄_S が ζ の符号をどこまで保つかを、ξ をそろえたまま比べられる。
3. 正の歪みは A < √2 なら 1 + δ > 0 で切り捨てが起きない。
   この模型で、真の基準で測った ζ̂ が上の式の ζ に合うことを先に確かめ、合ってから負の歪みと Q̄_S の比較に進む。
   負の歪みは g² > 1 + √2/A の点を切るので（A = 0.7 で約 8%）、式は目安であり、切った割合を今と同じく診断に書く。
4. 変換は乱数を使わない純粋な関数として Engine に置き、変換の種類を表す型はデータ契約に置く。Manager は g を作った後に Engine を呼ぶ。Client は `zeta_field` に変換を選ぶ引数を足し、既定は恒等とする。
5. 恒等変換のときは、乱数列・出力のファイル名・列・値を今と同じにする。変更前と後の実行ファイルに同じ引数を渡し、出力がバイト単位で一致することを確かめる。
   恒等でない変換のときだけ、出力のファイル名に変換の名前を足し、expected の列に上の式の ζ を書く（ρ は辺のビンの中心の距離で、中心の分布を一様とみなした近似）。
6. 測り方は今の G と同じにする（選択関数を模擬データから作り直す、S の幅 R を変える、Q̄_S と下がり方の表に足す）。

### 本 ADR で決定しないこと

- 振幅 A・場の幅 σ・W の幅 R_W の値と、作る個数。1 回分の時間と、正の歪みでの確かめの結果を見て決め、ノートと Issue に書く。
- 負の歪みを、店どうしの競合・市場の飽和・出店を避ける地域などの何と解釈するか。ノートの議論に委ねる。
- 点どうしが一定の距離より近づかない模型（hard-core）や、高い密度を頭打ちにする変換。この ADR の模型で Q̄_S ≈ −0.7 に届かなかった場合の次の候補とする。
- 中心の数が有限なことによる g のガウスからのずれの補正。正の歪みでの確かめで、ずれの大きさを見る。

## Consequences

- ζ の符号が正・0・負の三つの模型を、同じ地形・同じ W・同じ測り方で比べられる。
- ξ ∝ ρ² は、恒等変換の ξ ∝ ρ より速く r とともに下がる（ガウス関数の幅が √2σ から σ になる）。コスモスの 24 km までの ξ̂_S に合わせるには、恒等変換より大きい σ が要る。
- 正しい基準での |Q| は、正三角形で (2√2/3)/(A ρ) ≥ 0.94/A と大きい。S に吸い込まれた後にコスモスの −0.7 に届く余地がある。
- 負の歪みでは切り捨てが ζ を式からずらす。ずれの大きさは、真の基準で測った ζ̂ と式の比で見る。
- 同じ種で変換だけを変えると、同じ g から作った模型になる。この比較は「同じ場の形で変換だけが違う」と書き、独立な確かめとしては種を変える（リポジトリの CLAUDE.md の模擬データの決まり）。
- 選択肢が一つ増えるので、恒等変換での出力の一致を確かめる手間が増える。

## Alternatives Considered

- 点どうしが近づかない模型（hard-core、Matérn の間引き）：短い距離で ξ < 0 になり、コスモスの ξ̂_S > 0 と合わない。点の過程の新しい Engine も要る。
- 高い密度を頭打ちにする変換（δ = min(g, c) を標準化）：負の歪みを持つが、ξ と ζ が閉じた式にならず、模型の確かめが難しい。
- 対数正規の場（exp(g) を標準化）：正の歪みしか作れない。負の歪みに −exp(g) を使うと、低い側が切られる割合が大きい。
- NS の子どうしを近づけない：ζ は親のまわりの固まりから来る正の項が主で、符号が負にならない。
