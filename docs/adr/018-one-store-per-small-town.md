# ADR 018: 密度場の模型で、人口を町に分け、小さな町には店を一軒だけ置き、町の人口で置き方を決める

## Context

ADR-017 の Decision（町の中心を選びやすくする重み）では、店が町の中心に寄り、V・d_90 が悪くなった。そのとき、コスモスの「町の中心に一軒ずつ」は、点ごとの重みではなく店どうしの関係として入れる必要があると読んだ。

これを確かめるため、人口の格子（3 次メッシュ）を町に分けた。各格子のまわり 5 km の人口 P について、P がより大きい格子のうち最も近いものへつなぎ、D_t 以内にそれがない格子を町の中心とする（Rodriguez と Laio の方法）。店は最も近い格子の町に入れ、町の期待数 E_t = N T_t / ΣT（T_t は町の人口、N は店の数）の区間ごとに数えた（2026-11-17、`town_occupancy` の出力。hI1 は ADR-015 の本番の模型、A0 は場の揺らぎのない対照、各 20 回）。

D_t = 5 km（町 1038 個）：

|---|---|---|---|
| 0.1 未満 | 514 | 0.004、0.001 ± 0.001、0.027 ± 0.006 | — |

| 0.3〜1 | 167 | 0.509、0.410 ± 0.025（+4.0σ）、0.445 ± 0.024 | 0.729、0.590 ± 0.053（+2.6σ）、0.617 ± 0.052 |
| 1〜3 | 116 | 0.707、0.658 ± 0.017、0.633 ± 0.020 | 0.854、0.832 ± 0.030、0.797 ± 0.047 |

D_t = 10 km（町 567 個）でも同じ形で、E_t が 0.1〜0.3 の町では、店のある町の割合がコスモス 0.221、hI1 0.061 ± 0.018（+9.1σ）、A0 0.202 ± 0.034、二軒以上の割合がコスモス 0.000、A0 0.326 ± 0.115（−2.8σ）だった。

- 小さな町（E_t が 0.1〜0.3、人口およそ 7 千〜2 万）では、コスモスは人口に比例する置き方（A0）と同じ割合で店を置くが、二軒目をほとんど置かない。
- 中くらいより大きな町では、二軒目を避けていない。E_t が 0.3〜1 の町では、むしろ模型より二軒目が多い。
- hI1 は小さな町に店をほとんど置かない。ADR-015 の Decision の反応 h は、まわり 5 km の人口 P が P_0 = 12000 より小さい所を抑えるので、孤立した小さな町まで消す。ごく小さな町（E_t < 0.1）を避けるのはコスモスも同じである。

## Decision

1. `field_mocks` に、人口の格子を町に分ける選択肢（`--towns R:D_t`）を足す。分け方は Context と同じで、P の半径を R、町の中心どうしの最小距離を D_t とする。池の点は、R 以内で最も近い格子の町に入れる（なければどの町にも入れない）。
2. 町を使う二つの選択肢を足す。どちらも `--towns` と一緒のときだけ使える。
   - `--town-cap T_c`：人口 T_t が T_c より小さい町には、店を一軒までしか置かない。重みで受け入れた候補の町にすでに店があれば、退ける。
   - `--town-response T_0:m:T_1:s`：重みに、ADR-015 の Decision の h と同じ形で、P の代わりに町の人口 T_t を入れた h(T_t) をかける。
3. 既定では使わず、使わないときは乱数列も出力も今とバイト単位で一致することを確かめる。使うときだけ、出力の名前に `_towns{R}x{D_t}`、`_tcap{T_c}`、`_tresp{T_0}x{m}x{T_1}x{s}` を足す。
4. R = 5 km、D_t = 5 km とする。T_c は E_t = 0.3 に当たる人口（N = 1735、ΣT から求める）とする。T_0・m・T_1・s は短い実行（5 回、新しい種）で選び、合わせる量は `town_occupancy` の区間ごとの店のある町の割合と町あたりの店の数だけにする。
   比べる組は、hI1 に `--town-cap` だけを足したもの、`--pop-response` の代わりに `--town-response` を使うもの、その両方とする。
   確かめに使う量は、二軒以上の割合、`nearest_by_pop` の人口の少ないマスの d の中央値、d_90、V、κ̂₂、λ_c ≥ 3 のマスの店の数。
5. 短い実行で d_90 と V が近づき、ほかの量を崩さない組があれば、新しい種で 20 回測る。

- `--town-cap` を hI1 に足しても、ほとんど変わらない。hI1 は小さな町にそもそも店を置かないので、二軒目を止める場面がない。
- `--town-response` は小さな町に店のある割合をコスモスに合わせ、d_90 を初めてコスモスより長くした。一方、町（人口の山の流域）はまわりの人口の少ないマスまで含むので、人口 1 万未満のマスに店を置きすぎ、V と κ̂₂ が上がった。
- まわりの人口の反応を重ねると、人口 1 万未満のマスの店は減るが、二つの頭打ちが重なって大都市のマスの店がコスモスの半分以下になり、V と κ̂₂ は hI1 より悪いまま。
- どの組でも、人口の少ないマスの店の間隔（d の中央値 5.1〜6.8 km、コスモス 12.87 km）は伸びない。
- Decision 5 の本番は流さない。d_90 と小さな町の店は合わせられるが、そのとき V・κ̂₂・大都市の店の数が崩れる。どの町に置くか（町の人口）と町の中のどこに置くか（まわりの人口）を、互いに崩さずに与える形は、この ADR では見つからなかった。

### 本 ADR で決定しないこと

- 町の分け方を人口の山ではなく行政区域（市区町村）で決めること。
- 町の中での店の置き方（町の中心か、町の中に広く置くか）。まず池の重みのまま置く。
- T_c を E_t ではなく人口そのもので固定した値にすること。

## Consequences

- 「小さな町には一軒、大きな町には人口に応じて」という、実際の出店に近い形を、人口の格子だけで試せる。
- `--town-cap` は、選ぶ順で結果が変わる（先に選ばれた店が町を占める）。池の点を重みで選ぶ順はこれまでと同じ乱数で決まる。
- 合わせに使う町の割合はコスモスに合って当然になるので、V・d_90 とほかの量で確かめる。
- 町の分け方は D_t によるので、本番の結果は D_t = 10 km でも `town_occupancy` で確かめる。

## Alternatives Considered

- すべての町を一軒までにする：中くらいより大きな町では二軒目を避けていない（Context）ので、合わない。
- 町の数を数えるだけで、反応は ADR-015 の h(P) のまま：小さな町に店がほとんど置かれないことが残る。
