# ADR 011: 店をマスに数え、期待数からのずれの分布で負の歪みの出どころを調べる

## Context

ADR-010 の Decision（ガウス場を点ごとに変換して、ζ の符号を選べる密度場の模型を作る）で作った負の歪みの模型 G−（δ = A(1 − g²)/√2）は、コスモスの ξ̂_S、ζ̂_S の R による下がり方、Q̄_S を、同じ測り方で近く再現した（`notes/retail-cosmology-beyond.tex` の歪みを選べる場の節、2026-11-16 確認）。
三点相関関数は三点の積の平均なので、負の ζ が「高い密度の所が頭打ちになる」（飽和）から来るのか、「店が予想より少ない所がある」（穴）から来るのかを区別しない。
G− の密度 1 + A(1 − g²)/√2 は、上は 1 + A/√2 で頭打ちになり、下は |g| が大きい所で 0 まで下がるので、両方の性質を持つ。

一点の分布（マスごとの店の数の分布）は、この二つを区別できる。
穴は店が 0 のマスを増やし、飽和は店の多いマスを減らす。
今のコードには、点を約 10 km の粗い格子に数える関数 `engine::random_catalog::count_coarse_cells` がある（日本では 2 次メッシュ、緯度 5 分・経度 7.5 分）。
一方、密度場の模擬データ（`manager::three_point::field_mocks`）は店の位置をファイルに残さないので、模擬データの一点の分布を後から測れない（2026-11-16 確認）。

`field_mocks` は、単一幅の従来のコマンドでは、店の位置と、店と同じ手順のランダムカタログを一つの乱数列から順に引く。
ξ̂ と ζ̂ の数え上げはこの列を使わない（2026-11-16 確認）。

## Decision

1. 密度場の模擬データの Client に、1 回ごとの店の位置をファイルに書く選択肢と、ξ̂・ζ̂ の数え上げを飛ばす選択肢を足す。
   数え上げを飛ばしても、店の位置とランダムカタログを引く乱数列は同じにする。
   同じ種なら、数え上げを飛ばした実行と飛ばさない実行で店の位置が一致することを、実際に流して確かめる。
   どちらの選択肢も使わないときは、出力がバイト単位で今と一致することを確かめる。
2. マスごとの期待数 λ_c は、店と同じ手順で作る。
   店（実データまたは模擬データ一つ）から幅 R_W の選択関数 S を作り（今の proc の基準と同じ `SmoothRatio`）、
   λ_c = N × Σ_{i∈c} 人口_i S(c) / Σ_i 人口_i S(i) とする（N は店の数、i は人口の格子、S は粗い格子の中心で求める）。
   ランダムカタログを撒かずに重みを直接足すので、λ_c に乱数の揺らぎは入らない。
3. 期待数からのずれは、ポアソンの揺らぎを差し引いた量で表す。λ_c ≥ λ_min のマスについて、
   - 二次：κ̂₂ = Σ[(N_c − λ_c)² − N_c] / Σ λ_c²
   - 三次：κ̂₃ = Σ[(N_c − λ_c)³ − 3(N_c − λ_c)² + 2N_c] / Σ λ_c³
   - 空のマスの比：V = #(N_c = 0) / Σ e^{−λ_c}
   - 多いマスの比：H = #(N_c ≥ 2λ_c) / Σ P(N ≥ 2λ_c; λ_c)（P はポアソン分布）
   δ_c をマスの中の密度の平均のずれとして N_c がポアソン分布なら、κ̂₂ と κ̂₃ の期待値は δ_c の二次と三次のキュムラント（λ で重みをつけた平均）になる。
   V と H は、店の位置がポアソン分布ならどちらも 1 になる。
   計算は乱数を使わない純粋な関数として Engine に置く。
4. 比べる相手は、コスモスと、同じ R_W で作った密度場の模擬データ（ζ が 0、正、負の三つ）。
   加えて、場の揺らぎのない模擬データ（振幅 A = 0、W だけのポアソン点）を同じ手順で測り、対照とする。
   λ_c をカタログ自身から作るので、店のないマスでは λ_c が小さめに出て V が 1 より小さくなるなど、手順そのものが統計をずらしうる。
   その大きさを対照で見て、コスモスと模型は対照と並べて比べる。
   一つしかないコスモスは、模擬データ一つごとの標準偏差と、コスモス以下（以上）になった個数で比べる。
5. 結果の読み方は次のとおりとする。対照と G− に比べてコスモスの V が大きければ穴、H が小さければ飽和の寄与が大きい。
   どちらでもなければ、一点の分布ではこの二つを区別できないと書く。

### 本 ADR で決定しないこと

- λ_min の値（λ_c ≥ 1 などを複数試し、結果がどれだけ変わるかをノートに書く）。
- 飽和だけを持つ模型（高い密度を頭打ちにする変換）や、穴だけを持つ模型を作るか。この ADR の測り方で、コスモスと G− の違いが見えたときに、別の ADR で決める。
- 丸い塊の模型（NS）の店の位置を残すか。必要になったら `clustered_mocks` に同じ選択肢を足す。
- 空や多いマスを、競合・飽和・出店を避ける地域のどれと読むか。ノートの議論に委ねる。

## Consequences

- ξ̂・ζ̂ を測った模擬データと同じ店の位置で一点の分布を測れるので、三点相関関数の結果と一点の分布を同じ模擬データで並べられる。
- 店の位置を残すので、後で新しい測り方を足すときに模擬データを作り直さずに済む（1 回分は 1735 点で小さい）。
- 数え上げを飛ばすと 1 回分は場を作る時間だけになるので、既にある模擬データの店の位置を短い時間で作り直せる。ただし、乱数列の一致を確かめる手間が増える。
- 粗い格子は約 10 km で、W の幅 25 km より狭い。期待数 λ_c は小さい（多くのマスで 1 前後）ので、ポアソンの揺らぎが大きく、κ̂₃ は揺らぎやすい。比べるときは模擬データの標準偏差を使う。

## Alternatives Considered

- 模擬データを作るときに、一点の分布の統計だけを書く：店の位置を残さないので、λ_min や統計を変えるたびに作り直しになる。
- 期待数をランダムカタログを撒いて数える：撒く数の揺らぎが λ_c に入る。重みを直接足せば揺らぎがない。
- マスの幅を変えて並べる（counts-in-cells を幅ごとに）：粗い格子の関数をそのまま使える約 10 km だけで始め、必要なら後で足す。
