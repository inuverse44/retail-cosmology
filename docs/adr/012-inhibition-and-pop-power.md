# ADR 012: 密度場の模型に、店どうしが近づかない条件と、人口に比例するより緩い増え方を足す

## Context

ADR-010 の Decision（ガウス場を点ごとに変換して、ζ の符号を選べる密度場の模型を作る）で作った G10−（A = 0.7、σ = 10 km、R_W = 25 km）は、コスモスの ξ̂_S、ζ̂_S の R による下がり方、Q̄_S を、同じ測り方で近く再現した。
一方、ADR-011 の Decision（店をマスに数え、期待数からのずれの分布を見る）の測り方では、コスモスは空のマスが少なく（λ_c ≥ 1 で V = 0.556、場の揺らぎのない対照 A = 0 は 0.874 ± 0.111）、場のある五つの模型はどれも V = 1.20〜1.46 だった（2026-11-16、`cells_stats` の出力）。

最も近い店までの距離 d（`nearest_stats` の出力、2026-11-16）では、次のことがわかった。

- d < 1 km の店の割合は、コスモス 0.160、対照 0.229 ± 0.014（−5.0σ）。d < 0.5 km は 0.038 と 0.079 ± 0.009。d < 2 km では 0.478 と 0.479 で同じ。場のある五つの模型は 0.251〜0.281 で、対照よりさらに多い。
- 店のいるマスの期待密度で割った u = π n_c d² の不足は、λ_c ≥ 3 のマスに集まり（u < 0.1 が 0.097 と 0.188 ± 0.017）、1 ≤ λ_c < 3 のマスではほとんどない（0.207 と 0.220 ± 0.020）。避け合う距離はまばらな所で広がるのではなく、km でほぼ一定（1 km 前後）と見るほうが合う。
- 層に入る店の数と期待数の和は、コスモスで λ_c < 1 が 363 と 392.5、1〜3 が 619 と 515.7、≥ 3 が 753 と 826.8。対照（20 個の平均）は 397.5 と 384.7、491.9 と 478.6、845.7 と 871.7。コスモスは中くらいのマスに店が多く、濃いマスに少ない。

1 km 前後の避け合いだけでは、約 10 km のマスの空きは減らない。空きを減らすには、店を濃い所から薄い所へ移す、別の仕組みが要る。

`field_mocks` は、基準の重み（人口 × 実際の店の選択関数）で撒いた点の池から、重み w = max(0, 1 + δ) の棄却法で店の数だけ選ぶ（同じ点は選ばない）。三角形の辺のビンは既定で 2〜32 km の対数 4 個（2026-11-16 確認）。

## Decision

1. `field_mocks` の店の選び方に、二つの選択肢を足す。どちらも既定では使わず、使わないときは乱数列も出力も今とバイト単位で一致することを確かめる。
2. 近づかない条件（`--inhibit r:γ`）：重みで受け入れた候補について、すでに選んだ店のうち距離 r 以内にあるものの数 k を数え、確率 γ^k で受け入れる（γ = 0 なら r 以内に店を置かない）。
   k > 0 のときだけ乱数を一つ使う。近傍は池の点の格子（`util::spatial::UnitGrid`）で探す。
   選ぶ順は池からの無作為な順なので、逐次に間引く点の過程になる。
3. 緩い増え方（`--pop-power α`）：重み w に (人口_c / 人口の基準)^{α−1} をかける。人口_c は池の点が入る粗い格子（日本では 2 次メッシュ、約 10 km）の人口の和で、ADR-011 の λ_c と同じ規模。
   α = 1 なら今と同じ（計算もしない）。α < 1 なら、人口の多いマスの店の割合が人口の比より小さくなる。
   選択関数は今までどおり模擬データ自身から幅 R_W で作り直すので、R_W より大きい規模の差は選択関数に吸収され、R_W より小さい規模の濃淡だけが残る。
4. r・γ・α の値は、店の位置だけを作る短い実行（`--skip-measure on`、5 回）で、G10− を土台にいくつか試して決める。
   γ と r はコスモスの d < 0.5 km・d < 1 km の割合に、α は V に近づくものを選ぶ。合わせに使った量は結果の確かめに数えず、ノートにもそう書く。
   確かめに使う量は、ξ̂_S、ζ̂_S の R による下がり方、Q̄_S、κ̂₂、層ごとの店の数（合わせに使わなかったもの）。
5. 比べる模型は G10− に (a) 近づかない条件だけ、(b) 緩い増え方だけ、(c) 両方を足した三つ。それぞれ新しい種で 20 回ずつ測る。
   土台が同じ G10− なので、場の形は違う種で独立に作る（`--seed` を変える）。
6. ADR-010 では点どうしが近づかない模型を「短い距離で ξ < 0 になり、コスモスの ξ̂_S > 0 と合わない」として退けた。
   今回は r を 1 km 前後にし、正の ξ を持つ G10− と組み合わせる。r は三角形の辺の一番短いビン（2 km）より内側なので、測っている ξ̂_S・ζ̂_S に直接は入らない。
   実際に ξ̂_S が正のままかは結果で確かめる。

### 値を選ぶ短い実行の結果（2026-11-16 追記）

G10−（A = 0.7、σ = 10 km、R_W = 25 km）を土台に、種 100 で 5 回ずつ、店の位置だけを作った（`local_scan` の出力。コスモスは V 0.556、d < 0.5 km 0.038、d < 1 km 0.160、d < 2 km 0.478。G10− は 20 回で V 1.285 ± 0.147、d < 1 km 0.265 ± 0.016）。

| 組 | V | κ̂₂ | d < 0.5 km | d < 1 km | d < 2 km |
|---|---|---|---|---|---|
| r = 1 km、γ = 0 | 1.146 ± 0.132 | 0.027 ± 0.015 | 0 | 0 | 0.431 ± 0.015 |
| r = 1 km、γ = 0.3 | 1.120 ± 0.062 | 0.034 ± 0.021 | 0.024 ± 0.007 | 0.089 ± 0.013 | 0.454 ± 0.019 |
| r = 1 km、γ = 0.5 | 1.210 ± 0.061 | 0.019 ± 0.025 | 0.049 ± 0.003 | 0.157 ± 0.008 | 0.480 ± 0.015 |
| r = 1 km、γ = 0.6 | 1.210 ± 0.075 | 0.029 ± 0.017 | 0.063 ± 0.010 | 0.175 ± 0.014 | 0.494 ± 0.016 |
| r = 0.7 km、γ = 0 | 1.141 ± 0.116 | 0.015 ± 0.013 | 0 | 0.138 ± 0.003 | 0.460 ± 0.019 |
| α = 0.7 | 1.309 ± 0.131 | 0.150 ± 0.043 | 0.074 ± 0.009 | 0.201 ± 0.012 | 0.429 ± 0.012 |
| α = 0.5 | 1.348 ± 0.077 | 0.262 ± 0.030 | 0.057 ± 0.008 | 0.182 ± 0.016 | 0.397 ± 0.014 |

- 近づかない条件は r = 1 km、γ = 0.5 にする（d < 1 km と d < 2 km がコスモスに合う。d < 0.5 km は少し多い）。V はどの r・γ でも 1.12〜1.21 で、コスモスの 0.556 に届かない（Context の見込みどおり）。
- 緩い増え方は、α = 0.7 でも 0.5 でも V と κ̂₂ がかえって大きくなり、λ_c < 1 のマスの店も 608、772 個とコスモスの 363 個から離れる。期待数 λ_c は人口に比例するとして作るので、人口の冪を変えると λ_c からのずれが大きくなる。V を下げる向きに効かないので、Decision 5 の (b) と (c) は流さない。
- 本番は (a) だけを新しい種 12 で 20 回測る。V を説明する仕組みは、この ADR では見つからなかった。

### 本 ADR で決定しないこと

- r と γ を店の密度で変える形（商圏を分け合う形）。今の d の結果では、まばらな所で広く避け合う様子がないので、まず一定の r で試す。
- 緩い増え方を人口ではなく別の量（道路・商業地の広さなど）で表すか。
- 近づかない条件を、丸い塊の模型（NS）にも足すか。

## Consequences

- 一点の分布（V）と最近接距離という、三点の量とは別の性質を、模型の側で合わせられるかを試せる。
- 合わせる値を短い実行で選ぶので、選んだ量はコスモスに合って当然になる。結果を読むときは、合わせなかった量で比べる。
- 近づかない条件は、店の数が池の点の数に比べて小さい（1735 点と約 16 万点）ので、選べなくなることはまずない。それでも選べないときは止めて知らせる。
- 選ぶ部分の計算が少し増える（受け入れた候補ごとに近傍を探す）。1 回分の時間は流す前に測る。

## Alternatives Considered

- 近づかない条件だけで V も合わせる：1 km 前後の避け合いでは約 10 km のマスの空きは減らない（Context）。r を 5 km 以上にすると、測っている ξ̂_S の短いビンに入り、ADR-010 の反論がそのまま当てはまる。
- 店の密度で r を変える：d の結果（まばらなマスの d の中央値はコスモスのほうが短い）と合わない。
- 一点の分布を変える変換（飽和）を場の側に入れる：ADR-011 では飽和の兆しが見えなかった。人口の冪は、場とは別に人口の濃淡への反応を表すので、こちらから試す。
