# ADR 019: 密度場の模型で、店を置く町と、町の中の場所を二段に分けて決める

## Context

ADR-018 の Decision（人口を町に分け、小さな町には一軒だけ置き、町の人口で置き方を決める）の短い実行では、次のことがわかった（2026-11-18、ADR-018 の追記の表）。

- 町の人口 T_t に対する反応 h_T を重みにかけると、小さな町に店のある割合と d_90 はコスモスに届いた。ただし町はまわりの人口の少ないマスまで含むので、人口 1 万未満のマスに店を置きすぎ、V と κ̂₂ が上がった。
- ADR-015 の Decision のまわりの人口 P への反応 h_P を重ねると、人口の少ないマスの店は減ったが、h_T と h_P の頭打ちが重なり、大都市のマスの店がコスモスの半分以下になった。

二つの反応を重みに掛け合わせると、h_P は町の中での配分だけでなく、町どうしの店の数の配分も動かす。そのため h_T で合わせた町ごとの店の数が崩れる。

`field_mocks` は、池の点を一様に選び、重み w / max w の確率で受け入れる（棄却法）。選ばれる確率は w に比例するので、池の点ごとの重みを決めれば、どんな二段の選び方も同じ手順で表せる（2026-11-18 確認）。

## Decision

1. `field_mocks` に、二段に分ける選択肢（`--two-stage on`）を足す。`--towns`・`--town-response`・`--pop-response` と一緒のときだけ使える。
2. 二段のときは、反応をかける前の重みを b_i（密度場と、ADR-012・017 の重みまでをかけたもの）とし、町 t に入る池の点 i の重みを
   w_i = h_T(T_t) Σ_{j∈t} b_j × b_i h_P(P_i) / Σ_{j∈t} b_j h_P(P_j)
   とする。前の因子が町を選ぶ重み、後ろの因子が町の中の場所を選ぶ割合である。h_P は町の中での配分だけを変え、町ごとの重みの和は h_T と b だけで決まる。
   どの町にも入らない点と、町の中の Σ b h_P が 0 の町の点は、重み 0 とする。
3. 既定では使わず、使わないときは乱数列も出力も今とバイト単位で一致することを確かめる。使うときだけ出力の名前に `_2st` を足す。
4. ADR-018 の Decision 4 と同じ町（R = 5 km、D_t = 5 km）と T_c = 21812 を使い、短い実行（5 回、新しい種）で h_T の T_1 と h_P の P_0 を選ぶ。
   合わせる量は `town_occupancy` の区間ごとの店のある町の割合と町あたりの店の数、`pop_response` の区間ごとの ΣN/Σλ とする。
   確かめに使う量は、V、κ̂₂、d_90、`nearest_by_pop` の人口の少ないマスの d の中央値、λ_c ≥ 3 のマスの店の数。
5. 短い実行で、合わせる量を崩さずに V と d_90 が hI1 より近づく組があれば、新しい種で 20 回測る。

### 値を選ぶ短い実行の結果（2026-11-18 追記）

種 105 で 5 回ずつ店の位置だけを作った（`town_occupancy`・`pop_response`・`local_scan`・`nearest_by_pop` の出力）。町は R = 5 km、D_t = 5 km、h_T の T_0 = 7271、m = 3、s = 1。使わないときは、hI1 の短い実行と、ADR-018 の最も選択肢の多い組の店の位置が、どちらもバイト単位で一致した（cmp）。

|---|---|---|---|---|---|---|
| コスモス | 0.236 | 0.708 | 0.437 | 7.02 | 0.002 | 0.556 |
| hI1 | 0.077 ± 0.016 | 0.772 ± 0.057 | 0.523 ± 0.099 | 6.43 ± 0.37 | 0.013 ± 0.017 | 0.737 ± 0.090 |
| 二段、T_1 = 10⁶、T_c、h_P は C | 0.287 ± 0.033 | 0.647 ± 0.059 | 0.738 ± 0.065 | 6.79 ± 0.21 | 0.060 ± 0.016 | 0.859 ± 0.067 |
| 二段、T_1 = 3×10⁶、T_c、h_P は C | 0.203 ± 0.032 | 0.715 ± 0.042 | 0.686 ± 0.038 | 6.89 ± 0.23 | 0.030 ± 0.029 | 0.807 ± 0.030 |

| 二段、T_1 = 3×10⁶、T_c なし、h_P は C | 0.230 ± 0.031 | 0.715 ± 0.036 | 0.696 ± 0.047 | 6.67 ± 0.24 | 0.022 ± 0.023 | 0.789 ± 0.078 |

h_P の C は ADR-015 の (12000, 3, 5×10⁵, 1)。

- 二段にすると、ADR-018 で崩れた大都市の店の数が戻った（T_1 = 3×10⁶ で 30 万以上のマスの ΣN/Σλ が −0.2σ）。町の期待数の区間ごとの店のある割合と町あたりの店の数は、どの区間も 2.4σ 以内に入り、d_90 も +0.6σ に近づいた。
- V はどの組も hI1 より悪く（0.79〜0.86）、人口 3 千〜1 万のマスの店は多め（T_1 = 3×10⁶ で −6.5σ）、人口の少ないマスの店の間隔（d の中央値 5.6〜7.0 km、コスモス 12.87 km）は伸びない。
- hI1 で V < 1 が出たのは、h_P が町をまたいで店を中くらいの人口のマスへ寄せたからと読める。町ごとの店の数を h_T で決めると、その寄せがなくなり V が戻る。町の店の数・d_90・大都市の店と、V とは、ここまでの形では両立しない。
- Decision 5 の条件（合わせる量を崩さずに V と d_90 が hI1 より近づく）を満たす組はないので、本番は流さない。

### 本 ADR で決定しないこと

- 町を選ぶ段と場所を選ぶ段で、別々の乱数を使う（本当に二回に分けて引く）こと。重みで表せば足りるので、まず今の棄却法のまま試す。
- 町の中の配分を、P 以外の量（町の中心からの距離など）で決めること。

## Consequences

- 「どの町に何軒」と「町の中のどこに」を別々の反応で与えられ、片方を合わせたときにもう片方が崩れるかを確かめられる。
- 重みは町ごとの和を使うので、池の点の重みの準備が少し増える（町ごとに二つの和）。
- 町ごとの重みは池の点の数に比例するので、池の点が少ない小さな町では、町の重みも池の偶然の揺らぎを含む。

## Alternatives Considered

- h_P の P_0 だけを下げて、重みの積のまま使う：ADR-018 の短い実行で、P_0 = 5000 でも大都市の店の不足が残った。
- 町ごとの店の数を先に決めてから町の中に置く（店の数を固定する）：町ごとの数の揺らぎ（ポアソンより大きいか小さいか）も V に効くので、まず重みで試し、数を固定する形は結果を見てから考える。
