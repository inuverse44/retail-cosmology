# ADR 002: ビンをまとめた値は、単純な平均に jackknife の誤差をつける

## Context

ノートでは、いくつかの距離のビン（例：8.0–20.0 km の 2 ビン）の $\hat\xi_{\mathrm{LS}}$、店と人口の比、$dr/rr - 1$ を一つの値にまとめ、その値で「固まっているか」を判断している。
これまでは共分散 $C$ で重みをつけた平均（GLS、$m = \mathbf{1}^\top C^{-1}x / \mathbf{1}^\top C^{-1}\mathbf{1}$、`engine::estimator::gls_mean`）でまとめていた。
$C$ は jackknife（64 領域）で推定している。

店が数百しかないので $C$ は粗い。
GLS の重みは $C^{-1}$ で決まるので、$C$ の粗さが値そのものに入る。
2026-11-06 に、乱数の種を 1–6 と変えて確かめた。GLS、単純な平均、分散の逆数の重みの平均を並べて出すコミット 86bde19 の `scripts/bin_means.sh` で計算し、結果は `data/xi/bin_means_jp.tsv` に置いた（`data/` はコミットしない）。
種を変えると jackknife の領域の分け方が変わる。

- ビンごとの値は、種を変えても jackknife の誤差の 2 割以下しか動かない。
- GLS でまとめた値は、トライアルの選択関数 $R = 200\,\mathrm{km}$ で、種によって誤差の 0.47 倍動いた。
- ビンの間の相関が強いと、GLS は誤差の大きいビンに負の重みをつけ、値がどのビンよりも外に出る。種 1 のトライアル $R = 50\,\mathrm{km}$ では、ビンの値 0.056 と 0.103 から 0.118 を返した。$R = 200\,\mathrm{km}$ では、種 1 のビンの値が 0.40、0.45、0.45、0.21 で、GLS は種によって 0.15–0.30 を返した。

相関の強いデータを推定した共分散で GLS にかけると値が外に出ることは、原子核データの分野で知られている（References の 1）。

## Decision

ビンをまとめた値は、ビンの単純な平均（重み $1/p$、$p$ はビンの数）とする。
誤差は、jackknife の標本ごとに同じ平均をとって求めた標準偏差とする。
重みが前もって決まっているので、これは $\sqrt{\mathbf{w}^\top C \mathbf{w}}$ と一致する。

理由は次のとおり。

1. 重みがデータにも jackknife の領域の分け方にも依らない。上の確かめでは、日本のどの量でも、種による動きは jackknife の誤差の 0.15 倍以下だった。
2. 値は必ずビンの最小と最大の間に入る。
3. ビンの間の相関は、重みではなく誤差に入る。相関を捨ててはいない。
4. 「その距離の範囲での、対数距離について平らな平均」という、読み方のはっきりした量になる。GLS は「ξ がビンによらず一定」という仮定の下の推定だが、実際の ξ は距離で変わる。

### 本 ADR で決定しないこと

- まとめる距離の範囲（`manager::correlation` の `MID_RANGE_KM` と、選択関数つきで $R/2$ までとする規則）。
- 有意かどうかの判断の方法。帰無仮説の模擬データと比べることは変えない（ノート `notes/retail-cosmology.tex` の「誤差の見積もり」の節）。
- 全ビンで 0 と合うかを見る $\chi^2$。こちらは引き続き $C^{-1}$ を使い、上側確率は模擬データで校正する（`manager::calibration`）。

## Consequences

- まとめた値の誤差は GLS より大きくなる。上の確かめでは 3–5 割大きかった。誤差の大きいビンにも同じ重みをつけるからである。
- 誤差の大きい短い距離のビンの値が大きいと、まとめた値が大きくなる。西友の $R = 50\,\mathrm{km}$ では、種 1–6 の平均で 0.09 から 0.18 になった（誤差も 0.10 から 0.16 に増え、jackknife の $\sigma$ で数えると約 $1\sigma$ のまま）。
- 地方だけをそろえた帰無仮説の模擬データと比べた判断は変わらなかった。$R = 50$、$100\,\mathrm{km}$ の模擬データ 100 個（`data/xi/null_mocks_cross_TRIALxSEIYU_{50,100}_grid.txt`）では、トライアル、西友、相互相関のどれも、どのまとめ方でも実際の値に届いたものはなかった。模擬データの標準偏差で数えた離れ方は、トライアル $R = 50\,\mathrm{km}$ で約 $6\sigma$ から $4.5\sigma$ に下がる。
- 密集地への寄り方もそろえた模擬データ（`data/xi/null_mocks_cross_TRIALxSEIYU_{50,100}_density.txt`）と比べた西友の判断は変わった。GLS では 100 個のうち 20 個（$R = 50\,\mathrm{km}$）と 69 個（$R = 100\,\mathrm{km}$）が西友の値以上になり、「西友の固まり方は人の多い所に寄ることで説明できる」と読んでいた。単純な平均では 0 個と 2 個になる。差は $8.0$–$12.6\,\mathrm{km}$ のビン（$R = 50\,\mathrm{km}$ で $0.24 \pm 0.26$）から来ている。種 1 の GLS はこのビンに負の重み（約 $-0.27$）をつけ、どちらのビンよりも小さい 0.068 を返していた。ビンごとの値は変わっていないので、この読みの違いはまとめ方の選び方から来るものとしてノートに書く。
- ノートのまとめた値と、模擬データのまとめた値は、すべて計算し直す。

## Alternatives Considered

- **GLS のまま、いくつかの種で平均する**：種による揺れは減るが、値がビンの外に出る性質は残る。トライアル $R = 200\,\mathrm{km}$ では、種の平均 0.21 がどのビンよりも小さかった。
- **分散の逆数（$C$ の対角）で重みをつける**：重みは正なので値はビンの間に入り、誤差は単純な平均より 1–3 割小さかった。種による揺れも小さかった（誤差の 0.17 倍以下）。選ばなかったのは、重みがまたデータから決まり、何を平均したかの説明が一段複雑になるからである。
- **まとめずに、ビンごとの値と校正した $\chi^2$ で判断する**：$\chi^2$ は符号を見ないので、「正に固まっている」「負に避けている」を一つの数で言えない。
